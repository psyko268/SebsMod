# SebsMod

Mod til Schedule I (MelonLoader).

## Installation (én gang)
1. Installer MelonLoader i Schedule I.
2. Hent `SebsModUpdater.dll` herfra og læg den i spillets `Plugins`-mappe.
3. Start spillet. Opdatereren henter selv `SebsMod.dll` til `Mods`-mappen, og holder den opdateret hver gang spillet starter.

`version.txt` indeholder versionen og SHA-256 af `SebsMod.dll`; opdatereren tjekker filen mod den, før den bruges.
